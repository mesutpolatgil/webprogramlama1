# 🚀 Web Programlama I - Sistem Mimarları Operasyon Merkezi

Bu depo (repository), SCÜ Şarkışla UBYO Bilişim Sistemleri ve Teknolojileri Bölümü **Web Programlama I** dersinin resmi "Çevik (Agile) Operasyon Merkezi"dir. 

Dönem boyunca tüm modül çevirileri, mimari slaytlar ve uygulama kodları bu depo üzerinden, açık kaynak (open-source) sektör standartlarına uygun olarak yönetilecektir.

---

## 📌 İş Akışı: Görevler Sisteme Nasıl Yüklenecek?
Sektördeki gerçek yazılım ekipleri nasıl çalışıyorsa, biz de öyle çalışacağız. Bu depoya doğrudan dosya yükleme (Push) yetkiniz **yoktur**. Görevlerinizi teslim etmek için aşağıdaki **"Fork & Pull Request"** adımlarını izlemelisiniz:

### Adım 1: Projeyi Kopyalayın (Fork)
1. Bu sayfanın sağ üst köşesinde bulunan **Fork** butonuna tıklayın.
2. Açılan ekranda "Create Fork" diyerek bu deponun birebir kopyasını kendi GitHub profilinize oluşturun.

### Adım 2: Kendi Kopyanızda Çalışın
1. Kendi profilinizdeki kopyaya (repository) gidin.
2. Bilgisayarınıza indirin (`git clone`) veya doğrudan GitHub arayüzü üzerinden dosyalarınızı ekleyin.
3. **KLASÖR KURALI:** Yükleyeceğiniz tüm dosyalar (slayt, çeviri, kodlar) tek bir klasör içinde olmalıdır. Klasör isimlendirmesi şu formatta olmalıdır: `Hafta_XX_TakimAdi` *(Örn: Hafta_03_KodBucuk)*.

### Adım 3: Katkı Talebi (Pull Request) Gönderin
1. Kendi kopyanızda işinizi bitirip dosyaları kaydettikten (Commit & Push) sonra, kendi deponuzun ana sayfasına gelin.
2. **"Contribute"** (veya *Pull Request*) butonuna tıklayın ve **"Open Pull Request"** seçeneğini seçin.
3. Başlık kısmına `Hafta XX - [Takım Adı] Teslimi` yazarak PR'ı (Değişiklik Talebini) oluşturun.

### Adım 4: Denetim (Code Review)
- PR açtığınızda sistem asistanımıza (QA / Red Team Lideri) bildirim gönderecektir.
- Asistanımız kodlarınızı ve çevirilerinizi inceleyecek, eksik veya hatalı yerler varsa PR üzerinden size yorum yapacaktır.
- Gerekli düzeltmeleri yaptıktan sonra asistanınız PR'ı onaylayacak (**Merge**) ve dosyalarınız resmi ana depoya kalıcı olarak eklenecektir.
