Aşağıdaki kavramları birbirinden ayırarak kısaca açıklayınız:

**Web sayfası, web sitesi, web sunucusu ve arama motoru**

# 2. Dosya yapısı ve dosya yolları —

Bir web projesinin klasör yapısı aşağıdaki gibidir:

```text
my-site/
├── index.html
├── images/
│   └── logo.png
├── styles/
│   └── style.css
└── scripts/
    └── main.js
```

**a)** `index.html` içerisinden `logo.png` dosyasına ulaşmak için hangi dosya yolu kullanılmalıdır?

**b)** CSS dosyasının ve JavaScript dosyasının hangi klasörlerde tutulduğunu yazınız.

**c)** Bir dosya yolunda `../` ifadesinin anlamı nedir?

**d)** HTML içerisinde Windows'taki `\` yerine neden `/` kullanılır?

# 3. HTML —

Aşağıdaki HTML kodunu inceleyiniz:


**a)** Açılış etiketi hangisidir?  
**b)** Kapanış etiketi hangisidir?  
**c)** Öğenin içeriği nedir?  
**d)** `href` nedir ve ne amaçla kullanılmıştır?  
**e)** Bu yapı genel olarak ne olarak adlandırılır?

# 4. CSS ve JavaScript —

Aşağıdaki CSS kodunu inceleyiniz:

```css
p {
  color: navy;
  width: 520px;
}
```

**a)** `p`, `color`, `navy` ifadelerinin CSS'teki adlarını yazınız.  
**b)** `color: navy;` yapısına ne ad verilir?  
**c)** CSS'in bir web sayfasındaki temel görevi nedir?

Ardından şu JavaScript kodunu düşününüz:

```javascript
button.addEventListener("click", mesajGoster);
```

**d)** Bu kodda hangi kullanıcı olayı takip edilmektedir?  
**e)** JavaScript'in HTML ve CSS'ten farklı olarak web sayfasındaki temel görevi nedir?
